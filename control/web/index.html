What this architecture provides

Each workload has its usual OKE interface plus an IPvlan child on the RDMA PF. The physical NIC stays on the host. DRA reserves one RDMA NIC for one pod at a time.

Workload pods use their own network namespace and access the shared physical RDMA device. The Dranet infrastructure daemon is privileged. Hardware VF isolation is not provided.

Pair profiles use two free physical NIC claims; automatic MPI uses up to eight free workers, and the matrix checks each ordered pair of free workers sequentially. Test pods and claims are removed afterward. Each pair check runs one 64 KiB bandwidth test and one 8-byte latency test, each with 5,000 iterations. Results include average bandwidth, latency in microseconds, and available latency percentiles. Latency is perftest’s half round-trip estimate.
